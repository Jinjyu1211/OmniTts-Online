# OmniTts-Online

Omni Toolbox（树树妙妙屋）在线模块：**TTS 语音播报系统**。
对外提供统一的语音播报入口，默认走微软 Edge 的神经网络语音（音色自然、无需密钥），
其他模块可以直接调用它说话，而不用各自实现一套 TTS。

## 能做什么

- **Edge TTS**：微软 Edge 的在线神经网络语音，中文音色自然，无需申请密钥。
- **双备份**：断网或合成失败时可自动回退到系统 SAPI 离线语音，也可接自定义命令行程序。
- **连接自愈**：Edge 请求失败会自动重建连接重试（默认 2 次），连续失败进入限流冷却并在冷却期内直接改用系统语音，不会卡住。
- **播报队列**：后台线程串行播报，不阻塞游戏主线程；冲突策略支持排队 / 打断 / 丢弃。
- **音频缓存**：相同文本与参数只合成一次，重复播报零网络延迟；启用时自动预热快捷播报文本。
- **文本净化**：折叠换行、截断长度、去除 `<>` 与 `[]` 内容、游戏专有名词发音替换。
- **三种触发方式**：聊天命令 `/omni TtsSystem say 文本`、设置页命令列表里的「执行」按钮，以及供其他插件调用的 **Dalamud IPC** 接口（`OmniTts.Say` 等）。
- **可被其他插件调用**：其他 Dalamud 插件通过标准 IPC 即可播报，无需命令或反射，见 [docs/CALLERS.md](docs/CALLERS.md)。

## 在 Omni 中添加

插件设置 → 在线模块，填写仓库地址（或其 `TreeHouseModules.json` 的 raw 地址）：

```text
https://github.com/Jinjyu1211/OmniTts-Online
```

首次安装后模块默认关闭，在「树树妙妙屋 → 在线」中手动启用。

> **获取失败？** Omni 需要从 GitHub 拉取清单与模块文件，国内网络直连 `raw.githubusercontent.com` 经常不稳定。
> 请确认代理处于开启状态且覆盖游戏进程（建议 TUN / 系统代理模式）后手动刷新；
> Omni 启动时及每 6 小时也会自动刷新清单。开发与发布细节见 [docs/DEV-NOTES.md](docs/DEV-NOTES.md)。

## Edge 语音不可用时怎么办

Edge TTS 走 `speech.platform.bing.com`，与拉取模块用的是两条不同的网络路径：
浏览器能开 GitHub 不代表游戏进程连得上微软的语音服务（加速器 / 代理规则不同）。

模块本身已经做了兜底，按顺序：

1. **失败自动重试**：单次播报最多重建连接重试 2 次（设置页「合成重试次数」可调 0–3），重试之间指数退避。
2. **限流冷却**：连续失败 2 次后进入冷却（20 秒起，最长 120 秒）。冷却期内不再打服务端，
   **直接改用系统 SAPI 语音**，避免重试加重限流。设置页底部会显示剩余秒数。
3. **提前恢复**：确认网络恢复后，点设置页命令列表里的「重置网络连接」（或 `/omni TtsSystem reset`）可立即解除冷却。
4. **始终离线可用**：若网络长期不稳，把「引擎」切到「系统 SAPI（离线）」即可完全不依赖网络。

> 只想让常用提示语稳定出声：保持「缓存合成音频」开启，同一句话合成过一次之后就不再联网。
